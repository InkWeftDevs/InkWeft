CHAPTER 03 微分学 · 概念与应用

导数与变化率

从一段时间里的变化，走向某一时刻的变化。

01从平均变化率出发

设位移是时间的函数 s = f(t)。在区间 [t, t + Δt] 内，平均速度是位移增量与时间增量的比值。

v̄ = ΔsΔt = f(t + Δt) − f(t)Δt

几何上，它对应曲线上两点间割线的斜率。

02让时间间隔趋近于零

当 Δt 越来越小，平均变化率趋向某一确定值，这就是瞬时变化率。

导数的定义
f′(a) = limh → 0 f(a + h) − f(a)h

前提：这个极限存在，且为有限值。

h ≠ 0；趋近于零，不是等于零。

03几何意义：切线斜率

割线的极限位置，就是切线。

在 x = a 处，切线方程为：

y − f(a) = f′(a)(x − a)
别混淆

导数是一个数；导函数是一个函数。
可导必连续，连续未必可导。

04例题 · 在 x = 1 处求 y = x² 的切线

  1. 1代入定义，展开增量：
f′(x) = limh → 0 (x + h)² − x²h
= limh → 0 (2x + h) = 2x
  1. 2求斜率：f′(1) = 2，切点为 (1, 1)。
  2. 3代入点斜式：y − 1 = 2(x − 1)。
∴ y = 2x − 1

先求导，再代入；别先把 x 换成 1。

留一个问题

函数 f(x) = |x| 在 x = 0 处连续，为什么不可导？分别考察 h > 0 与 h < 0 时的差商。

右侧斜率 +1，左侧斜率 −1 → 左右极限不同。
理解定义 → 观察图像 → 计算 → 解释01
h > 0：|h| / h = 1
h < 0：|h| / h = −1
