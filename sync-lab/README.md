# 合成双客户端同步实验 v1

这是独立模型与可运行实验，未连接 Android 作者数据库，不作为产品同步开关。

运行：在安装 `backup-server/requirements.txt` 的 Python 环境执行 `python -m unittest discover -s sync-lab -v`。

## 最小合同

- 范围固定为 server／issuer／account／library；设备需被 Relay 明确授权。标题不是身份。
- 操作 ID 幂等，载荷固定。每对象以父版本集合表示因果关系；不同对象自然合并，相同对象的并发头全部保留。
- 人工内容优先于派生识别；派生修改不能移除人工头。多个手工版本仍须显式解决。
- 墓碑保留，与离线编辑并发时保留两个分支。重放已见操作不重建对象。
- 一次应用先在隔离状态验证 note／page／ink／attachment／card／source／live_map／resource 的引用闭包，失败不改变游标或内容。不认识的类型拒绝整个批次。
- 同步独立 AES-GCM 密钥、独立随机 nonce；`inkweft.record-sync.v1` AAD 绑定身份、设备、操作、密钥版本。设备密钥包装另用 `inkweft.sync-grant.v1`；不复用备份密文块或 nonce。
- 游标过期必须显式重新基准化；未提供自动快照重基准实现。未知密钥版本阻断直到提供对应授权密钥。

## 实际范围

四项实验覆盖离线并发、重复请求、删除与编辑、人工修正、卡片与来源／实时图引用、缺附件、错误账号、游标过期、密钥换代及设备撤销。

载荷是受控合成 JSON，尚未覆盖 Android 全部 IWO9、笔划、资源、历史及事务编码。内存 Relay 不是网络同步服务器；授权和密钥发放仍由实验调用者提供。离线设备已持有的明文／密钥无法远程抹除。真实库双向同步保持关闭。
