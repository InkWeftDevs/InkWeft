# V87 · 绘制分配、大页读取与原件空间

版本 `87 / 0.0.87-bounded-resources`，基于 `bf2c091`。本轮目标是减少绘制中的重复分配、控制大页几何工作集、流式交换大文件并回收实际磁盘空间，以及提供可重复的定向验证入口。

## 实现与边界

- 铅笔按新增采样段维护瓦片候选索引，索引用整数数组；静止重绘复用索引，视口、笔迹内部采样和配方改变时重新建立。保留几何上限 65,536 点、候选权重 131,072，继续受全局显示资源预算约束。
- 编辑读取用可重建计数表和擦除目标索引，避免每次移动视口读取整页身份/点数表。单次读取受 65,536 点、256 笔的流式批次和载荷预算限制；密集编辑窗口会缩小，完整显示仍分批完成。撤销保存身份，窗口只补读当前区域，不因撤销历史长期保留离屏几何。
- 图层编辑只保留页头、对象归属和当前窗口的笔迹归属；整层移动/删除使用数据库条件，撤销用数据库差异记录恢复离屏及隐藏成员。待提交日志保存有限投影和操作身份，重启后按回执核对。
- 页、本复制逐笔映射身份并逐条复制图层归属，不再保留整页 ID 映射。对象来源、隐藏/锁定图层、删除标记、版次、搜索索引和回执继续校验。
- `.iwpage/.iwbook` 的界面导入导出改用文件及 SQLite 暂存索引，复用流式归档校验器，工程上限 8 GiB。同一原件只输出一次；目标身份在导入时重新映射，取消、校验失败或源版次变化不发布不完整副本。
- 可见 PDF/PNG 分享逐批绘制笔迹，输出落暂存文件。两格式均使用最长边 4096、最多 800 万像素的有界位图；PDF 是光栅可见副本。PDF 背景最长边 2048、图片采用已存预览（最长边最多 1024）；不嵌入隐藏内容或原始文件。需要可编辑笔迹或原件时使用内容交换文件/全库备份。
- 只读来源、资料库内容封面和页面缩略图采用分批渲染。整页识别只汇集笔迹身份与边界，再按行分批读取并栅格化；继续使用既有 20,000 笔/100 行识别预算，保留隐藏图层、美化来源与荧光笔过滤。源版次改变时丢弃结果，不写入半页索引。
- 新 PDF/图片原件按 SHA-256 存入不可变文件，先完成校验、同步及原子发布再写入数据库引用；渲染直接租用原件，避免再生成同尺寸缓存。相同原件跨本共享。缺失原件不会从旧渲染缓存回填，流式复制和归档会校验完整摘要。
- 设置中的“整理原件与磁盘空间”迁移旧块、清理无引用且无租约的原件/中间文件，随后回收 SQLite 空闲页并截断 WAL。旧库首次可能需要 VACUUM 的额外空间；不足或数据库忙时保留资料并报告延期。回收站及可能供历史使用的原件归属仍保留，不把逻辑字节数当作已释放空间。
- 全库备份和 Shadow 小样本同步复用原件文件的归档行适配；原件和作者数据仍按原有事务、闭包和重放规则验证。Shadow 仍是独立测试实验室，维持 2,048 行/8 MiB 上限。

几何和文件字节量不再要求整页、整本常驻。编辑窗口和图层撤销不持有完整成员表；批注、对象、识别及单次作者操作保留各自预算，SQL 中的作者数据和撤销差异仍随实际内容增长。这些优化不构成无限页面容量、恒定总内存或所有设备无卡顿的承诺。

## 格式及恢复

Room 18→19 增加原件摘要、页内笔迹/掩码身份及图层查询索引，并新增图层撤销差异表，作者表数据保留；计数、擦除关联、空间表和会话撤销差异不进入作者归档。大页完整校验使用有索引的有界批次，避免每批重新排序全页。旧 SQL 原件块在显式整理后才删除，删除前完成完整长度/摘要校验。

新流式 `.iwpage/.iwbook` 需要 V87 或后续支持版本。界面停止直接导入旧的整份载入格式：先在原版本导入，再升级后重新导出；也可先在原版本建立完整资料库备份后恢复。旧安装包不能读新流式内容和 Room19 数据；不承诺长期兼容旧包。降级须在独立环境从升级前备份重建，不直接打开升级后的库。签名及用户设备资料未被删除。
