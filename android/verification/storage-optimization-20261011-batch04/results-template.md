# 第四轮存储优化结果记录模板

每台设备、每个 APK 独立追加记录；待测项目不得填为通过。主用例入口为[真机测试清单](../../DEVICE-TEST-CHECKLIST.md)的 SO4（含 SO4-SQLITE-01）、MEM-LEAK、PERF-MACRO 项。

| 字段 | 记录 |
|---|---|
| 日期、测试人 | 待填 |
| APK、SHA-256、包名 | 待填 |
| 源码版本与补丁归档 | 待填 |
| 设备型号、物理设备/模拟器 | 待填 |
| Android / API、内存、可用空间 | 待填 |
| 屏幕刷新率、动画倍率、温度、电量 | 性能测试必须记录 |
| 资料准备 | 独立合成资料 / 已备份副本；描述笔数、点数、页数 |
| 用例编号及具体步骤 | 待填 |
| 预期结果 | 待填 |
| 实际结果 | NOT_RUN / PASS / FAIL / BLOCKED |
| 出错时刻及复现步骤 | 待填 |
| 诊断 ZIP、录像、原始 runner、trace 或堆分析 | 待填 |
| 测试包卸载、临时资料及环境恢复 | 待填 |

软件问题优先在应用中标记时间、复现并执行“诊断与导出”，再补充日志无法表达的界面或笔感录像。基础诊断包不等于完整系统日志。模拟器功能验证不替代物理手写、泄漏检查或 Macrobenchmark 性能测量。

SO4-SQLITE-01 需分别记录首次新库4096-byte页/WAL、既有1024-byte库页大小及内容保持、损坏文件保留、noBackup路径和测试前后临时种子集合。真机未执行时填写NOT_RUN；本轮模拟器定向回归由device-results.md单独记载。
