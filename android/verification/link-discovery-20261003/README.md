## 实现

- 摘要卡固定底栏提供“查看反向引用”；关闭面板返回原卡片／节点／视口，打开另一对象才清掉旧卡片节点上下文。文档设置入口明确命名“链接与反向引用”。
- 关联页使用当前对象与所属笔记头部、发出／反向分组、完整宽度的关系卡片、文本预览和空状态。宽窗侧栏400dp，窄窗全宽；导出选项放到列表末端展开。
- 反向引用只包括正式 REFERENCE，比较完整 TargetRef（种类＋UUID）。首页和整本共用UUID时不会混为一个对象。同名对象展示所属笔记。
- 原正文链接与关联面板共用预览。预览保存焦点、关系ID、关系修订和方向；每次读取及打开前验证原关系。关系改指、删除、换类型或归属错误不自动跟随替代项。
- 反向预览读取引用来源的当前正文，不把目标固定修订套到来源；发出预览保持精确历史。历史缺失不补当前内容，目标回收仍可显示可读的固定摘录但不能打开。区域笔迹修订变化保留核对提醒。
- 预览观察已有Room表失效通知，正文单独更新也刷新；只读浏览不会生成作者回执。读取失败可以重启单个读取任务。长目标标题放在滚动区，预览关闭／打开独立保留；卡片操作可换行。

无数据库／格式、依赖、版本号、包名或签名变更；不新增图引擎、图数据库、编辑器或外部服务。AGPL许可证不变。
