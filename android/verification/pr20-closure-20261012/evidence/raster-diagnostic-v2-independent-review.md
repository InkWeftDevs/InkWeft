**hex/result 有足够明显的实测 CPU 成本，支持尝试最小一行替换**：保持原 `digest()` 调用、顺序和字节结果，仅把 `digest().joinToString(""){"%02x".format(it)}` 改为 `digest().toHexString()`，不改缓存、查询、epoch 或 nativeStroke 复用。候选该段 CPU 在三种层数累计 0.478/1.316/1.511 秒，占两段回调 CPU 的 32.2%/40.1%/49.0%。该段仍含 SHA finalization 和结果封装，尚未逐项隔离 Formatter，但候选优化范围正对已有热段且输出可直接验证。

已读取 [Kotlin 官方 API 当前页](https://kotlinlang.org/api/core/kotlin-stdlib/kotlin.text/to-hex-string.html)：ByteArray 的方法标注 Since Kotlin 2.2，每字节两位，默认示例为无分隔小写十六进制。项目 Kotlin 2.3 的实际可编译性仍由新构建验证，不用文档冒充编译。旧 `%02x` 接收 Byte，等价性应覆盖所有 256 字节值、前导零/高位负 Byte 和实际 32 字节摘要，确认长度 64、字符和顺序一致。
