## 扩展设计决定

先在现有模块内集中声明式纸面定义、关系类型和导出格式；内置实现先走同一入口。第三方扩展不能直写数据库或替换保存／恢复确认界面。代码插件、云服务及自动识别未具备隔离／授权／数据验证时不提供可执行入口；声明权限不能当作沙箱证明。真实可替换实现出现时再扩展 Provider，避免提前建立空模块和虚假插件市场。

## 本轮检查与边界

核心测试 195 项，数据库测试 125 项；界面检查覆盖新建、知识连接、多脑图共享、装饰线、答案保护及查看来源后返回同一题。最终界面总数、旧包升级、APK 摘要和 CI 状态以 `dist/UI-R2/交付回执.md` 为准。模拟器为独立测试实例 Android 12，普通回归 1280×800dp；额外检查 400dp、130%／200% 字号，已修复资料库顶栏挤压。

- 局部图限定一跳／二跳及节点／边数；不提供全库无限图。
- 学习范围当前按笔记选择；多脑图共享本笔记卡片。跨笔记本学习集、图文白板、多格式素材后置。
- 搜索覆盖标题、键入文字、有效人工索引和独立摘要；未覆盖自动 OCR、PDF 或图片。摘要命中进入摘要搜索，不能冒充原文。
- 引用展示为有界预览；未实现嵌套卡片无限展开。白板装饰线和脑图父子关系分别存储。
- 笔盒窄屏当前使用原生菜单；尚未完整复刻原型底部抽屉。字号 200% 下允许标题换行／截断，功能入口应保持可达。
- Markdown / JSON Canvas 是有损交换快照，输出映射与降级信息；完整恢复使用 `.iwbackup`。
- 新属性支持会话内撤销，其他知识操作不承诺跨重启撤销。诊断 ZIP 仍是有限事件及环境快照。
- PDF／图片留白、自动 OCR／AI、FSRS、同步、第三方可执行插件未启用。真实笔压、掌拒、Pencil 按钮、延迟与温升均待真机。
