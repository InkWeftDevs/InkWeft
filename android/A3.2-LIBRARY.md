# A3.2 资料库与内容副本增量

本轮按用户要求继续整合，实机测试集中到后续；不因此跳过自动化检查。没有授权合并main或创建Release。

## 行为

- 真正置顶与收藏分开。置顶项在当前筛选内优先，组内继续按标题或最近排序。相同目标状态重试不反转，旧版本不能覆盖不同的新设置。
- 从书架复制已保存的可见页面、文字、纸面、封面、文件夹和标签；仍有效的人工转录映射到新页头。副本有独立笔记/页面/笔迹/擦除身份，不影响原件。默认不复制置顶、收藏、隐藏笔迹、撤销/历史/回执、阅读视野或未保存草稿。
- 书架直接导出：纸张笔记整本iwbook，无界笔记iwpage。准备一致的已保存快照，展示明文范围，由用户选择输出位置。它不是完整备份，不是PDF，也不代表提供方已完成远端同步。
- 导入先按内容头校验，不信任扩展名、文件提供方size或available()。页面4,000,000bytes、整本32,000,000bytes；仍按笔迹与每页预算校验。校验和预览完成前不写库，确认后整批事务写入新笔记。
- 复制/导入使用固定命令和资料回执，同一请求结果未知时查原回执，不重复新建。Android保存状态只记录命令身份，不保存正文或文件缓存。进程重建若需要输入，用户重新选择相同摘要文件后重试；不自动保持长期文件权限。

## 边界

32MB是格式上限，不是所有设备对最大文件均已完成性能验收。读取/编码是有界内存实现，不宣传零拷贝流式。纯内容副本不是密文备份，擦除只是内容可见性操作，不是安全永久删除。

Schema6仅增加置顶列和资料操作回执表；原字节与页面身份不变，不使用破坏性迁移。生成schema必须由真实KSP输出并通过干净重建门禁。自动化结果以本轮CI原始报告为准，不把上一轮118/44/25结果移作本轮。

云服务继续DISABLED，自动手写识别、完整备份、长笔中途保存、跨进程撤销、PDF和学习卡片未在本轮实现；37AX保持NOT_RUN。

## 构件与测试

保持org.inkweft.app.a0.insertion包名，版本0.0.7-a3.2-library。CI仍是调试密钥，覆盖升级必须检查证书，不能自动卸载/清库。用户本轮不需要安装另一个小版本。

新增纯核心用例13项、Room用例13项、App用例4项。定义不等于执行。包括真实超过4MB的多页数据、短读/零进度、损坏、未知结果重放、原件不变、5->6真实迁移、目录复制/置顶/导出界面与ContentResolver接收路径。测试输出目标为测试自有URI；第三方提供方对话框/云上传不是已验收事项。
