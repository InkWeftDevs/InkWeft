# v38 实机状态

本轮适用包为墨织工作台预览 0.0.38-note-first（38），准确构件身份见 [验证记录](VERIFICATION-V38.md)。

vivo iPA2673 的 USB 调试可连接，但复核时仍为受保护锁屏，安装版本为v37。本轮没有在设备上卸载、清空或编辑用户资料，也没有完成v38覆盖安装；NF38-01—NF38-09全部保持NOT_RUN。已经提出解锁请求，收到回复后应安装同一交付APK，再执行清单中的普通用户步骤。

模拟器采用有内容密度的合成笔记完成界面检查，其结果不能替代实机通过。真实手写笔的压感、倾斜、掌拒、持续书写、温升和密集页性能继续单独待测。备用设备故障测试不在用户主设备执行。

步骤、预期结果和证据记录格式见 [独立实机清单](DEVICE-TEST-CHECKLIST.md#ui-nf1--v38-浮动导图实机清单)。出现问题时记录复现时间，优先从应用内“诊断与导出”生成ZIP，并补充操作步骤或视觉证据；该包不是完整系统日志。
