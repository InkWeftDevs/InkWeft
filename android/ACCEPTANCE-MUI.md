# 导图 UI 整改验收矩阵

输入为《InkWeft-导图UI整改-Codex.md》。在 v40 的 `8e159a7` 上增量实施，保留全部已有成果；生产代码 `a9b5bb0`。没有重置工作树、换框架或引入第二套主题。

## 实际差异

- MindMapView 分离选择、改名、详情和移动回调；加入双击与拖动阈值区分、独立折叠命中、共享屏幕矩形及边缘按钮避让；改名时拒绝冲突拖放。
- NodeActions／NodeTitleEditor 负责四个 48dp 图标和原位输入；目标冻结，组合输入未结束时不提交。标题草稿在稳定状态层保存。
- StudyWorkspace 负责现有命令和状态；新分支仅在确认后用原 CREATE 事务写入。共享卡仍是唯一名称权威，结构主题仍属于当前图定义。
- CardInspector 单独负责明确打开的内容阅读；MapMenu 将图级动作分成三组。原 StudyDialog 继续用于需要完整表单的场景。
- MapScenePainter 固定标题两行，与命中、连线、投递预览、页内图共用 MapNodeMetrics；不显示正文作为标题续行。
