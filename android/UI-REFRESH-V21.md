# v21 界面实施记录

本轮通过用户提供的 Notein 截图、[Notein 手写工具说明](https://help.notein.ai/category/handwriting-tools?lang=en)、[收藏笔说明](https://help.notein.ai/category/handwriting-tools/pen-favorites?lang=en)及 [Apple 工具栏规范](https://developer.apple.com/design/human-interface-guidelines/toolbars)参考交互。原始截图与竞品素材没有进入应用或 Git；横向笔形由本地 Canvas 独立绘制。

使用 ui-ux-pro-max 查询后，首个设计系统结果包含营销落地页结构，不适合笔记工作台，因此没有采用该结构。改用其简约工具界面与 Compose 主题建议：内容优先、统一层次、原生点击反馈、48dp 触摸区域、滚动与字号适配。Apple 风格用于操作分组和视觉层次，未复制 Apple 专有图标或字体。

## 操作变化

1. 主笔盒按左右位置转向；拖动柄负责移动，也能点按选择左右放置。底部减号收起，笔图标恢复。
2. 主笔盒星号打开独立收藏区；在任意笔参数卡片点星号保存当前草稿。收藏与应用分开，取消参数卡片不改变当前笔。
3. 收藏保存笔型、颜色与粗细，最多 12 支；点收藏笔应用到书写槽位，荧光笔保留原有透明度。取消收藏从该配置的参数卡片执行。
4. 参数卡片使用真实笔迹预览、图示笔型、粗细预设和渐粗滑轨；颜色与自定义色保持可达，参数只影响之后的书写。
5. 资料库、标签页、设置与学习界面统一蓝白层次及圆角。设置／诊断固定在分类栏底部，设置页可控制收藏区显示、自动美化并重置笔盒位置。原始文档、笔迹和封面配色不随界面主题改变。

## 范围

- 当前仍是浅色主题；系统深色设置下的可读检查不等于完整深色主题。
- 参数卡片只提供已实现功能；压力曲线、出墨速度、稳定性和一笔成形列入待办。
- 本轮没有改变文档格式、保存事务、自动美化或识别引擎；相应能力边界沿用 v20。

实机操作与结果见 DEVICE-TEST-CHECKLIST.md 的 T53—T54；安装包回执单独记录。
