# A2 原生资料库与无界工作台

在A1诊断版之上实现，不修改main或声明正式发行。实际CI/设备结果以PR报告与构件记录为准，不用本文代替验证。

## 实现范围

- 白色资料区、浅侧栏、真实笔迹预览；纸张/无界筛选，标题/已输入文字/标签搜索（不是手写OCR），网格/列表，名称/最近修改排序。
- 收藏、单层文件夹/多标签、未分类、回收站与恢复。文件夹/标签通过笔记菜单创建；没有空文件夹管理、批量操作或PDF筛选假入口。
- 新建可选择固定纸张或无界笔记，空白/横线/方格/点阵；所有预览对应真实绘制，不复制商业模板、图标或字体。
- 编辑器收起常驻调试横幅；必要保存/错误状态继续可见。诊断与导出在主页和编辑器都可达，不记录新加入的分类内容、画布坐标或笔迹。
- 每笔独立粗细面板，黑/红/荧光与整笔橡皮、撤销/重做；笔盒上下停靠。自定义宽度仅限当前会话，未宣称永久预设库。
- 纸张默认适宽，另有适页；无界支持有符号世界坐标、手指平移、焦点缩放、回原点和适合内容；保存每本笔记的视图，视图失败与作者数据保存分开。
- 世界坐标安全范围为每轴±1,000,000作者单位，不是无限资源承诺；当前仍1000笔/100000点/8192点每笔预算。渲染只创建视口大小表面，网格有界，可见笔迹绘制、网格缓存最多128笔，不分配巨大位图。
- 原件点坐标不随移动缩放重写。新增IWS2显式世界笔迹格式，固定页IWS1保持可读。页面副本IWP2携带形式和纸面；旧IWP1能导入为固定纸张。
- Room v2→v3加表迁移，不清库；旧文件夹/页面没有则创建普通纸张默认。擦除在后台计算，绘制遵守作者顺序，隐藏笔迹保留。

## 安装与已有资料

CI预览使用独立applicationId `org.inkweft.app.a0.workspace`，名称“墨织工作台预览”，与旧诊断版并存。无需卸载旧版；从旧版主动导出.iwpage，在新主页“导入副本”创建新笔记。不会自动跨应用读取数据库。

新.iwpage包含可见内容、文字、模式和纸面；不包含隐藏笔迹、撤销栈、命令回执、分类和视图，所以不是完整库备份，也未加密。目标存储提供方由用户选择。不要让测试APK保存唯一副本。
