## 自定义封面 · 2026-09-26

版本 `0.0.13-custom-covers`（13），数据库 Schema 10。

- 修复资料库搜索后立即打开笔记菜单时键盘收起的时序；模板测试按稳定键滚动，避免把未进入可见区的模板判为缺失。
- 新建笔记和资料库“更换封面”共用封面编辑器：本地图片、取景缩放与位置、六位自定义色号、独立封面标题、副标题、文字开关及书签标签／底部色带／简约标题三种排版。
- 内置纯色封面改为更清晰的书签标签构图，封面文字随缩略尺寸缩放；笔记名称仍在封面外支持系统字号。
- JPG／PNG／WebP／HEIF 图片经系统文件选择器导入，读取上限 20 MB；应用保存最长边 1024px 的 JPEG 副本，单图不超过 180 KB，去除原始图片元数据。不依赖原图 URI 长期授权。
- 图片取景可反复修改或重置，移除图片后可保留配色与文字；切回内置样式保留最近一份自定义设计，方便重新使用。取消不写库。
- 自定义封面随整本复制独立保存，随完整备份恢复；Schema 10 新增独立封面表，读取 Schema 6—9 旧备份。封面不占正文页，不改变笔迹、摘要及稳定身份。
- 内部封面图片预算合计 32 MB；普通 `.iwpage`／`.iwnote` 内容副本仍不携带封面，完整迁移使用 `.iwbackup`。

本地核心 199 项、数据库 129 项、界面 57 项通过；lint 为 0 错误、53 警告。实际最终构件、升级及 CI 检查见 `dist/Custom-Covers/交付回执.md`。本轮实机新增 T25—T27，升级和备份重点复测 T01、T14。

- 新增卡片手工属性、别名、按标签／状态筛选的集合；属性可在本次会话撤销。集合是视图，不复制摘要正文。
- 新增一跳／二跳局部关联图与关系列表，图形位置不改变关系；独立脑图共享卡片正文并分别保存层级和位置，自由白板的摆放与装饰线不成为正式关系。
- 新增独立回忆题，明确显示答案后再手工标记；可查看真实来源页并返回原题，查看本身不评级。标记确认提交后才进入下一题，无虚构到期时间或算法熟练度。
- 增加含关系映射与降级说明的 Markdown / JSON Canvas 快照导出；完整学习资料仍用 `.iwbackup`。
- Schema 9 新增知识记录、不可变修订及操作回执三张表；整库备份覆盖 21 张作者表，读取 Schema 6/7/8 归档，并保留同签名覆盖安装路径。

## A3.5 · 学习工作台测试版 · 2026-09-26

版本：`0.0.10-a3.5-learning`，versionCode `10`，数据库 Schema `8`。交付源码为 `4b01998c65326a70fed30907de0071eb79173004`，本次整理文档不改变该 APK 的源码版本。

### 新增与完善

- **框选与套索**：选择完整笔迹，移动、原位复制后拖开、改色、删除；“只擦框内部分”精确擦除选区覆盖部分，支持撤销与重做。
- **稳线美化**：对选中的普通笔迹进行几何平滑，可调强度、对比原迹、预览、取消、确认及撤销。保留端点、锐角、时间与轴数据；暂不处理已局部擦除的笔迹及荧光笔。
- **摘录摘要卡**：从选区保留当时可见的原迹快照，手工填写标题和摘要，记录来源页、修订及区域，可返回来源。来源变化或回收时提示，原快照仍保留。
- **共享卡片、大纲与基础思维导图**：两种视图共用节点及卡片数据；支持子主题、调整上级、防止循环、同卡复用、拖动、平移缩放、适配全部和自动排布。移除叶节点保留卡片；有活动引用的卡片不能直接回收。
- **搜索与导出**：按摘要标题、正文搜索；Markdown 导出保留大纲层级和共享卡片链接，每张卡片正文只输出一次。
- **整库备份**：Schema 8 新增 5 张学习表；`.iwbackup` 覆盖 18 张作者数据表，包括卡片、版本、来源、节点及回执，并可读取 Schema 6/7 旧备份。
- **覆盖安装**：本地工作台包固定使用已有开发签名；新增 A3 versionCode 5 / Schema 4 到 A3.5 versionCode 10 / Schema 8 的实际保留数据升级验证。

### 修复

- 思维导图绘制越界覆盖学习工具栏：在原生视图绘制层裁剪。像素回归在旧包复现失败，在修复包通过，并检查实际截图。
- 美化预览取消后重开仍无法应用：使用独立来源快照及可重放状态，明确计算、就绪、失败和重试；5 秒超时，阻止旧强度及迟到结果覆盖当前请求。
- 页面移动／复制预览长时间停在“核对中”：读取结果改为可重放状态，8 秒超时覆盖 IO 派发和读取全程，支持重试。
- 美化弹窗内容可滚动，操作区独立；修复重复运行时资料库改名测试被同名旧数据干扰的问题。
