# 笔刷 B1 实施记录

日期：2026-09-27。版本：`0.0.25-brush-recipes`（25）。方案评审见 [B1 差距评审](BRUSH-DESIGN-REVIEW-B1.md)。安装包、实际验证与限制见 [v25 交付说明](DELIVERY-V25.md)。

## 已实现

| 笔种 | 行为 | 参数 |
| --- | --- | --- |
| 圆珠笔 | 固定圆尖、实心等宽；不额外使用默认输入平滑 | 粗细、颜色 |
| 钢笔 | `r + (1-r) * p^q` 控制宽度，默认 r=0.40、q=0.90；默认短轴0.85、45°固定轻椭圆；无压力用0.65合成值，作者压力仍为−1 | 粗细、颜色、压感灵敏度、圆润笔尖、笔尖扁度 |
| 铅笔 | 固定石墨颗粒；压力控制浓度，轻微影响宽度；有效倾斜30°至60°扩大铺色，最高4倍；缺压固定0.5，缺倾斜不铺宽 | 粗细、颜色、偏硬／HB／偏软、浓度、颗粒、倾斜铺色 |
| 毛笔／马克笔／荧光笔 | 保留 v24 的独立压感／速度曲线、实色斜尖或透明斜尖 | 原有粗细、颜色 |

铅笔浓度使用 `hardness * density * (0.18 + 0.55 * sqrt(p))`；宽度为 `w0 * (0.85 + 0.15 * sqrt(p))`，在候选公式上保留低压力可读性。同笔采用覆盖范围内的最大沉积值，不按帧数或重复事件加深；不同笔迹按顺序 alpha 叠加。当前铺色为圆形扩大，不声称笔杆旋转或按方位角定向。

参数修改即时生效，关闭保留；收藏保存全部配方，同一收藏可继续修改。样笔标注“模拟压力样例”，保持等比显示。试写区可清空、切笔及留样对比，只使用面板内内存，不接笔记、识别、诊断或备份写入入口；关闭销毁试写状态。试写区显示设备轴存在情况，不能据一次等压输入推断硬件不支持压力。

## 渲染取舍与边界

锁定 `androidx.ink 1.1.0-alpha09`，未升级依赖或提高 minSdk。实际能力探针确认 TilingTexture 在 Android 12 软件画布上有纹理，但后续像素检查发现该路径没有保留预期的逐点压力透明度。因此铅笔采用统一的局部材质渲染，实时、历史、跨页、缩略图和试写均使用 `PencilRenderer`；其它笔种继续使用原生 Ink。

铅笔仍保存路径、轴值、配方和减法擦除遮罩，位图块只是可丢弃的显示缓存。纹理通过确定性整数算法生成，不下载商业纹理素材，无资源磁盘读取。共享96个64×64块，每块RGBA加浮点沉积场，容量约3 MiB；另有16 KiB基础纹理与短期绘制数组。该数字是缓存容量，不是整个应用内存占用。

材质采样格随作者坐标原点移动，固定 seed 与资源 SHA-256；复制新建身份但保留花纹。局部擦除只裁剪覆盖，不改变剩余纹理。整笔擦除改为与可见轮廓相交，避免铺色漏擦和擦到不可见中心线。OCR 使用扣除擦痕后的黑色覆盖，省略石墨噪声。

钢笔与圆珠笔 B1 使用明确的 passthrough 输入模型；不新增等待窗口、坐标稳线、速度辅助或强制收尾尖刺。8–16ms 压力低通仍属候选调优，当前未启用。笔尖扁度是几何参数，界面不把它描述成尚未实现的收锋效果。上述取舍优先保证新旧笔迹稳定和跨页一致。

原生 [TilingTexture 文档](https://developer.android.com/reference/androidx/ink/brush/BrushPaint.TilingTexture)用于核对材质接口；是否满足完整效果以本项目的实际像素测试为准。

## 保存合同

- 每笔落笔时冻结 `StrokeAppearance`：配方版本、参数、随机相位、材质原点。压力／倾斜是否存在按本笔首点和输入设备范围确定；压力0保留，缺轴为−1。
- 使用实际活动 pointer，支持手指先接触后手写笔加入；同位置同时间更新保留最终轴值。归一化作者样本没有被替换成渲染压力。
- 新笔迹使用 IWS5，笔种使用固定 wire ID；0—4保留原含义，铅笔为5。逐笔写入完整配方和资源摘要，不依赖可变收藏。未知配方／资源明确拒绝读取。
- 跨页分段保留同一材质原点与种子，并携带页边相邻采样作为渲染上下文，避免在接缝重新生成端帽；上下文随移动、复制和副本一起保存。
- 页面复制、整本复制、改色、几何稳线、内容副本、备份及恢复均保留配方；旧 IWS1—4 绑定 `legacy-v24`，不使用新笔盒设置重新解释。
- 自动字体转换不自动处理铅笔；主动框选换字体仍是另一个输出类型。

**格式影响：** Schema12和IWO4不变，但 v25 新笔迹及含它们的副本／备份不能交给旧版本读取。更新前保留备份；回退旧版时使用更新前备份或新建旧版测试库，不自动删除设备笔记。只能冻结旧数据到已知的v24基线，无法恢复过去未保存的历代配方。

## 验收边界

自动化覆盖外观编码、资源校验、备份恢复、逐笔冻结、混合pointer、试写隔离、压力浓淡、倾斜、重绘、自交、复制、擦除、跨页及局部材质CPU耗时。真实手持笔的中文细画、掌拒、笔尖延迟、温升和倾斜方向仍需按 [实机清单 B1-T01—T08](DEVICE-TEST-CHECKLIST.md)记录，不能用模拟输入或离屏图代替。

本轮不增加笔迹对象旋转／缩放、PDF／图片视觉导出后端、实体铅芯物理模拟、速度辅助、压力低通或出墨速度控制。已有可编辑 `.iwpage`／`.iwbook` 与整库备份完成配方传递。
