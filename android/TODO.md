更新日期：2026-09-26。当前开发版为自定义封面 `0.0.13-custom-covers`。已完成能力见 [修改日志](CHANGELOG.md)，当前范围见 [UI-R2 实施记录](UI-R2-IMPLEMENTATION.md)。以下为建议执行顺序，不代表已经排期或实现。

需要实机执行的操作已单列为 [真机测试清单](DEVICE-TEST-CHECKLIST.md)，包含准备条件、逐步操作、预期结果和反馈模板；后续每版同步维护。这里保留开发优先级，实际测试结果按设备和版本单独记录。

## P0 · 先稳定当前测试版

- [ ] **平板真机书写验收**：在用户实际设备测试连续书写、压力／倾斜、掌拒、笔身按钮、横竖屏、分屏、长时间运行与温升。记录设备型号、系统、笔型号及复现步骤；模拟器结果不替代真机笔感。
- [ ] **高密度与旋转兼容性**：复现 MuMu 384dpi 配置下缩略图发现、封面选择、工具栏可见性 3 项失败；区分布局缺陷、模拟器行为和测试定位问题。修复后复测相关场景。
- [ ] **观察异步预览稳定性**：反复打开／取消美化、快速切强度、页面移动／复制、旋转及后台恢复；核对超时、失败重试和迟到结果。现有修复与最终 CI 已通过，保留后续设备回归，不认定原内部机制已完全查明。
- [ ] **覆盖安装长期流程**：后续工作台包保持包名和固定密钥，递增 versionCode；每次记录源码、APK 摘要及证书。对历史异签名包补充导出／迁移路径说明，并实测数据保留，不能以卸载清库解决冲突。
- [ ] **恢复与故障验收**：实测进程终止、低空间、导入中断和备份损坏；确认不丢原始笔迹、不报告虚假保存成功、未知结果可查询或重试。

完成标准：用户目标设备上的书写／选择／美化／页面整理／备份恢复可复现验证，当前 3 项兼容性问题有明确结论；保留原始失败与修复证据。

## P2 · 新增核心学习能力

- [ ] **PDF 导入、阅读、批注与导出**：先做小闭环；明确页面坐标、缩放、摘录来源和导出保真，覆盖大文件与异常文件。
- [ ] **自动手写 OCR 与搜索**：现有手写索引是人工转录；先评估中文、公式、混排和离线方案。识别结果作为可修订派生内容，保留原笔迹与版本对应关系。
- [ ] **AI 自动摘要**：当前摘要卡由用户填写，云服务未启用；先确定输入范围、隐私与离线／联网方式。生成内容可编辑、可追溯来源，不覆盖用户正文。
- [ ] **字体式笔迹美化**：与已有几何稳线分别设计；确认文字和公式语义、原迹保留、可撤销与失败退回，再决定识别／生成方案。
- [ ] **闪卡与复习（FSRS）**：基于共享卡片设计问答投影与复习记录；明确卡片修订、排程和备份恢复，避免复制出多份不同步正文。
