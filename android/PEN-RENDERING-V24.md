# V24 笔型校准与可见内容编辑

## 发现与依据

2026-09-27，读取用户指定测试笔记的压力汇总，不导出文字、图片或坐标。vivo 平板确实上报了压力：5 笔毛笔共 1292 个样本，归一化压力中位数 0.1468254、最大值 0.33174604。旧版先将压力平方，再映射到笔宽的 12%～100%；中位压力下，默认宽度 8 实际仅约 1.11。用户反馈“毛笔比钢笔细”有明确原因。

本机 Notein v2.1.3.0 当前钢笔预设显示：粗细 0.5、压感 100%、出墨速度 100%、稳定性 50%；圆珠笔预设显示粗细 0.2、稳定性 50%，不显示压感控制。这是当前预设的界面实测值，并非对所有安装或出厂默认值的断言。第二种笔和铅笔入口弹出会员页，未购买、未声称完成这些笔型的实写比较；原笔记内容未修改，最后恢复钢笔。

[Goodnotes 官方笔工具说明](https://support.goodnotes.com/hc/en-us/articles/7353756785679-Write-and-customize-ink-with-the-Pen-tool)区分圆珠笔的固定线宽、钢笔的压感和毛笔更明显的压感，并将石墨效果归于独立铅笔工具。[Notein 官方手写工具目录](https://help.notein.ai/category/handwriting-tools?lang=en)同样区分钢笔／圆珠笔、铅笔纹理、荧光笔等。两者没有公开完整压力曲线，V24 的曲线是墨织自己的校准，不能把其他软件界面的 0.5 直接等同于墨织的作者坐标宽度。

## 本轮实现

| 笔型 | 笔尖与响应 |
| --- | --- |
| 圆珠笔 | 圆头、均匀线宽，不随压力变化 |
| 钢笔 | 略扁、倾斜笔尖，适度压感；未上报压力时随速度变化 |
| 毛笔 | 圆润笔尖，较大压感动态范围；压力使用 0.55 次幂，改善低压力区间；无压感时快写收细 |
| 马克笔 | 不透明斜尖，方向不同产生不同宽度 |
| 荧光笔 | 半透明斜尖，用于覆盖标注 |

墨织本轮仍没有石墨纹理铅笔。前两支是独立预设槽，可设成不同笔型，也可以同型不同参数。实时书写、参数预览、保存后重开均共用一套渲染规则；原始压力和坐标不改写。自动美化转成字体后按字体参数绘制，不保留原笔尖纹理。

顶部笔按钮直接展开笔盒并打开当前笔参数。图片可自由拉伸宽高，完成后手指点图片可再次选中移动；手写笔仍可在图上批注。套索按扣除擦除区域后的可见轮廓选择，完全擦除的笔迹或字形不会入选，移动／复制继续保留擦除遮罩。

## 受影响范围

钢笔、毛笔的显示规则更新，因此旧笔迹重新打开时外观也会更新；原始采样、颜色、标称宽度、擦除遮罩和存储格式保留。没有清空笔记，也没有新增旧渲染版本兼容层。V24 测试清单单独记录实际验证及待测的真实笔感项目。
