# 笔记优先界面 · UI-NF1 实施记录

基于 v37（当前分支 `2d64391`），保留摘录页内编辑、全选、分屏、笔刷、保存回执和完整备份。输入方案压缩包及参考图仅在本机 `archives/2026-09-28/NoteFirst/` 归档；未将网页原型当作原生实现或验证证据。

## 入口与容器合同

|稳定 ID|用户名称|默认位置／交互|可用条件与恢复|
|---|---|---|---|
|pen|笔|快捷栏一级；选笔，再点调参|沿用现有笔刷与参数即时保存，仅影响后续笔迹|
|eraser / lasso|橡皮／套索|一级；首次选中，再点参数|保持当前擦除、可见几何和混合选区语义|
|excerpt|摘录|一级图标与短名；再次点击方式、去向|选区与拖放预览不写作者数据；确认后使用原事务|
|map|导图|一级图标与短名，全屏仍可打开|恢复同一笔记的导图会话，不创建第二个笔记编辑器|
|undo / redo|撤销／重做|一级|沿用笔迹／对象域；导图的撤销添加位于导图内|
|document-add-page / quick-overview / book-search|加页／概览／查找|文档行一级|活动笔画与待核对操作期间保持禁用|
|toolbar-more|更多工具|低频工具、自定义入口|保留既有显示、隐藏和排序偏好|

|容器|行为|尺寸与命中原则|
|---|---|---|
|笔参数|常用与高级替换同一张卡，保留实时调参|常用：小样、粗细、颜色；48dp 触控区，不通过缩字达标|
|普通参数卡|锚定 Popup，无整页压暗|目标宽 320dp，有限高度内可滚动，外部关闭事件不能误写|
|FloatingStudyWindow|应用内容层；标题拖动、右下角调整、最小化、主动停靠或放大|初始 420×340dp；按安全区限制，窄高区域可折叠；纸面外部继续可写|
|导图管理与编辑|在同一浮窗内按需替换内容|表单显示时隐藏窗框缩放热区，避免遮挡提交动作|

窗框位置使用设备偏好；图坐标、共享卡片与来源仍通过仓库写入。最小化移除原生图视图，保留会话和可保存界面状态。图适配优先保留可读字号；超出当前视窗的节点通过平移查看。

## 数据约束

- 新摘录使用既有 `StudyCommand.CREATE` 将来源、卡、节点和回执原子保存；增加目标图版本核对，仍检查笔迹／对象来源版本。
- 拖动仅携带本进程内的来源草稿，系统剪贴数据不含来源图片和私人文字。近邻连接预览使用虚线；失败保留原选区，未知结果核对原 operationId。
- 撤销添加移除本次出现位置；只有尚未被修改或引用的初始卡才进入回收区。不会硬删后来复用的正文。
- 六种模板采用 `MapDefinition` 内的结构主题，不产生占位 `StudyCard`。独立图的结构主题和卡片出现位置共用层级校验。
- 个人模板是声明式节点索引、布局与标题，不包含卡 ID、来源、答案或文件引用；默认标题匿名化，保留标题需主动选择。
- `MAP_V2` / `MAP_TEMPLATE_V1` 使用封闭字段、节点和层级预算；完整资料库备份保留结构与模板。新内容不承诺可由旧版恢复；普通 `.iwbook` 内容副本仍不包含完整知识图。

## 验收记录原则

使用同一个最终候选 APK，以有正文、公式、批注和导图的合成资料验证。正常书写、参数卡、浮窗、拖放虚线、窄屏和 1.5 倍字号分别留图，并实际点按控件。语义节点存在、网页原型检查或 ADB 触控均不能替代真实手写笔的压感、倾斜、掌拒及持续书写观察。

最终结果、版本身份、未验证项目由交付记录及 `DEVICE-TEST-CHECKLIST.md` 逐项更新；此文件是实施合同，不宣称全部验收已完成。
