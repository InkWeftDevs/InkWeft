# 墨织 v31：美化保色与四栏概览

版本 `0.0.31-beauty-overview`（31），安装名称“墨织工作台预览”。已固定签名覆盖安装到连接的 vivo 平板。

## 本次修复

原字体美化整批只取第一笔的颜色，铅笔又被画成不透明字形。现在逐字保留来源颜色，铅笔按原压力、硬度和浓度保留浅淡效果与颗粒；保存重开、改字体、局部橡皮及撤销重做仍使用这些外观数据。已有美化对象保留了原笔迹身份，可以在显示时恢复外观，不改原位置或已擦除区域。

同一字内部用多种颜色书写时，字体替换采用对应局部来源笔色；不承诺逐笔复刻原字的笔锋。无法找到原笔迹的旧对象保持保存的颜色，不能凭空恢复丢失信息。

## 文档概览

平板USB核对StarNote后，概览改为四栏，回收区放在页面栏的垃圾桶入口和设置中。

| 栏目 | 本版可用操作 |
| --- | --- |
| 页面 | 缩略图、列表／平铺、选页、添加、页面菜单及回收区 |
| 大纲 | 将当前页加入目录、标题、视觉缩进、移除、按实际页序显示、搜索与跳页 |
| 页签 | 当前页添加、同页去重、改名、移除、搜索与跳页 |
| 摘录 | 现有手写摘录列表、标题／正文搜索、返回原页原位置、进入编辑、新建摘录入口 |

大纲与页签按页面身份保存，页面移动后页码随之变化；页面回收后隐藏索引，恢复后重新显示。摘录原页回收后显示来源不可用，仍可编辑摘要。大纲父子折叠／拖动排序、PDF原生目录导入、摘录缩略图尚未实现，已列入待办。
