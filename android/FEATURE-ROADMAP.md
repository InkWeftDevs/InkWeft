# 编辑器功能对照与下一步

更新：2026-09-27。当前测试版：0.0.16-page-objects（16）。用户提供的 StarNote 截图仅作为功能与操作场景参考，没有复用原图、插画、模板或文案素材。

## 现在能做什么

| 能力 | 当前实现与入口 | 边界 |
| --- | --- | --- |
| 多种笔 | 两个常用书写槽可各选圆珠笔、钢笔、毛笔、马克笔，另有荧光笔槽；点击已选笔或笔设置 | 毛笔是压感曲线与粗细变化，不是墨水扩散、笔毫纹理模拟；无压力输入回退定宽 |
| 多笔记标签页 | 编辑器顶部保留打开的笔记，点标签切换，× 关闭，＋ 打开回资料库 | 关闭不删除笔记；未保存文字拒绝关闭；新启动从资料库进入，打开任一本后恢复保存的标签列表 |
| 上下连续翻页 | 文档更多 → 上下连续翻页；也可在阅读与笔记设置切换 | 纸张笔记适用；手指滚动、触控笔书写；当前按适页宽度显示，精确缩放和套索切回单页；无界画布沿用平移缩放 |
| 套索与圈选擦除 | 编辑更多 → 套索、圈选擦除与摘录，或工具栏选择图标 | 矩形／自由套索、移动、复制、改色、整笔删除、只擦选区内部分；单页操作 |
| 摘录 | 选中笔迹 → 摘录为摘要卡，保留来源区域 | 当前是区域摘录与手动摘要，不是 OCR 摘录笔，也不自动识别原文 |
| 标签 | 文档更多 → 阅读与笔记设置 → 文件夹与标签；资料库同样可编辑和筛选 | 笔记级多标签；页面内标签标记尚未实现 |
| 额外设置 | 每本记住连续阅读方式；编辑更多切换工具栏顶部／底部；笔型颜色粗细、橡皮模式、纸面、目录与回收区 | 工具栏位置为本机通用偏好；暂未提供侧边工具栏、双页阅读和旋转页面 |
| 图片封面 | 新建和资料库更换封面 | 封面与页内图片独立保存 |

补充：[实际安装与操作记录](COMPETITOR-HANDS-ON.md)，包含成功操作、启动限制和具体改进点。

## 页内对象已交付范围

版本 16 已实现图片／系统相机／文本框／矩形胶带及共享拖动、缩放、复制、删除、对象撤销，纳入导出和备份。入口是工具栏「＋」，完整边界见 [PAGE-OBJECTS.md](PAGE-OBJECTS.md)。图层、混合套索、图片裁剪、文字对齐尚未实现；下面保留最终目标，不能把整组目标当成本版完成项。

## 下一组：图层与对象深化

优先级按用户当前反馈调整为：**图片导入／拍照 → 文本框 → 胶带 → 图层**。一组功能共用一套选择、拖动、尺寸、层级与撤销语义，避免每种对象独立存储、独立复制和独立导出。

1. 页面对象：稳定对象 ID、所属页面、画布坐标、类型、层顺序、可见与锁定；笔迹保持原采样，不把现有手写栅格化。
2. 图片导入：系统图片选择、方向修正、受限解码与大小预算、持久化本地副本；移动、缩放、删除、撤销、复制和备份恢复一起交付。不能仅保存会失效的临时 URI。
3. 拍照添加：调用系统相机写入受控临时文件，确认后进入与图片相同的插入流程；取消、拒绝权限、后台返回、存储不足均不产生幽灵对象。
4. 文本框：页面定位与尺寸、字体大小／颜色／对齐、重新编辑、键盘遮挡处理，与笔迹一起选择移动。现有“键入文字”是整本正文，不冒充页内文本框。
5. 胶带：明确为可揭开的遮挡复习对象，提供遮挡／揭开状态；导出时明确状态。底层原迹保留，不用橡皮或白色笔迹伪装。
6. 图层：基于同一对象顺序支持新增、改名、重排、隐藏、锁定及当前层；擦除／套索遵循可见与锁定规则，撤销与导出保持一致。先不做复杂混合模式。

完成标准：插入 → 操作 → 撤销 → 保存重开 → 复制／导出／备份恢复的闭环可验证，再加入下一类型。预计需要当前数据模型与备份格式演进；允许早期破坏性更新，变更时给出准确说明，避免默认承担旧格式兼容层。

## 后续阅读与输入优化

- 连续模式的双指缩放、缩放后横向平移、手指书写与滚动策略、跨页工具动作，以及大量页面的性能实测。
- 页内图片裁剪、PDF 导入及批注、文本／手写识别摘录、链接与自动化摘要。
- 笔刷更多纹理、个体压力曲线与实时稳线，先根据真实设备笔感决定，不只增加名称。

## 扩展设计判断

保留声明式模板注册和内部笔刷／页面对象类型边界即可。暂不引入可安装第三方代码插件、插件商店或动态脚本运行时；它们会增加数据访问、版本、资源和故障隔离成本。图片／文本／胶带／图层先使用当前应用内的明确类型与命令。稳定两轮真实需求后再决定外部插件协议。

## 参考依据

- [Goodnotes：笔工具与笔型](https://support.goodnotes.com/hc/en-us/articles/7353756785679-Write-and-customize-ink-with-the-Pen-tool)：参考定宽与压感的区别，以及常用笔设置。
- [Android Ink：笔刷接口](https://developer.android.com/develop/ui/compose/touch-input/stylus-input/ink-api-brush-apis) 与 [StockBrushes](https://developer.android.com/reference/androidx/ink/brush/StockBrushes)：使用原生圆头、压感与斜头笔刷及毛笔自定义压力尺寸行为，共用实时／重开／预览绘制路径。为使用公开的自定义笔刷 API，Ink 固定为 1.1.0-alpha09（[发布记录](https://developer.android.com/jetpack/androidx/releases/ink)）；这是预发布依赖，升级后的实机笔感仍需验证。
- [StarNote 官方网站](https://www.mystarnote.cn/) 与 [官方商店介绍](https://play.google.com/store/apps/details?hl=zh&id=com.onyx.galaxy.global.note)：功能范围参考；标签、连续翻页和设置的具体优先级来自用户截图与明确反馈，不把截图视为底层技术规范。
- [Notein 官方网站](https://www.notein.cn/)：连续阅读与书写场景参考。

未把零散商店评论当作性能证据；当前具体优先级来自这次用户反馈。相同名称不意味着实现和体验已经达到其他产品的水平。
