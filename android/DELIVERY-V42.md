# v42 · 自然字体美化与纸面校对

版本 `0.0.42-natural-beauty`（42），包名 `org.inkweft.app.a0.workspace`，沿用固定开发签名，覆盖安装“墨织工作台预览”。本机安装包：`E:/Inkweft/dist/BeautyQuality/InkWeft-v42-workspace-preview.apk`；准确摘要与构建身份见同目录 `artifact.json`。

## 使用

1. 点击实时美化入口，选择字体和开启开关。原位模式保持原行位置，使用自然字体比例；字号随原行估计。
2. 新写文字候选稳定且空间允许时自动转换。不确定内容保留原迹，点“美化待校对”检查；不逐字弹卡。
3. 框选美化打开校对卡。可以改识别文字、换字体；“查看原迹／查看纸面结果”在同一位置比较。点应用保存，点保留原迹取消。
4. 需要指定字号、行距和重新断行时，显式选择“段落”。纸面会显示实际结果，越界不能应用，相邻内容相交会提示。
5. 美化结果仍可局部擦除、整字擦除、撤销和恢复原迹。旧美化结果升级时保留原样；需要新排版时先恢复原迹再重做。

## 当前限制

真实小样本严格 CER 从 18.2% 降至 9.1%，但只有单人、5 段／22 字符，自动门槛放行率仅 20%。这不是通用准确率；数字混淆、空格、复杂行仍可能需要校对。未更换模型，未实现通用数学公式识别。

IWO9 新对象及新备份需本版或后续版本读取，不支持降级旧 APK 后读取；升级不清空资料。真实笔长停顿补写、英文补点、持续书写和温升仍按独立清单验收。
