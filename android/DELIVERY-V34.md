# 墨织 v34：混合缩放与选择修正

版本 `0.0.34-selection-refinement`（34），安装名称“墨织工作台预览”。

## 用法

1. 进入套索，按需在参数卡筛选内容；空选区点“全选本页”，或自己圈选。
2. 混合选中后点“更多 → 放大10%／缩小10%”。图片、文字、图形、胶带与手写围绕共同中心缩放，操作后继续保持选中。
3. 一次撤销／重做作用于整组。笔宽、胶带轨迹和美化字迹的局部擦除孔洞一起变换；普通文本按字号同比调整，符号保留原生文字渲染。
4. 套索模式与类型筛选自动保存，切工具和重新启动后仍保留；返回键可取消混合选择。

超出纸面、笔宽、字号或对象尺寸限制时，整组操作不生效并保留原件。全选按筛选后的可用原始笔迹数量限制为256笔，超出需分批圈选。图片按矩形范围选择；精确图形选择使用实际内缩边框并裁剪到对象范围。
