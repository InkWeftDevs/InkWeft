# V77 平板反馈修复与公式编辑

版本 `77 / 0.0.77-tablet-feedback`，基于界面整理分支 `5916cb0087154d8bef8c4717b548cbeb36678880`。本轮处理擦除闪烁、自动美化入口、笔橡皮切换和可编辑公式。最终安装包身份和验证结果在收尾时补齐；不能把中间候选的通过记录当成最终包全量通过。

## 使用方式

- 编辑器第二行工具栏的 **更多工具 → 自动美化** 始终可用，已保存的隐藏配置也能找到这个入口。
- 切换笔和橡皮只选择工具；再次点当前笔，才打开笔参数。
- 自动美化中选择 **公式美化**，再选 **框选公式**；停笔自动识别也生成待校对候选。核对函数名、分子分母、上下标后应用。
- 候选和已保存公式都有排版预览与 LaTeX 编辑，提供分式、上下标、根号和 α 插入按钮。点按公式后选择 **编辑公式**。
- 应用前保留原迹；应用后可撤销，或选择 **恢复原迹**。修改公式内容／字号会重新排版并清除该公式的局部擦除；只打开并保存未修改内容保持原状态。

## 实现与资料格式

擦除重建期间保留旧帧的未变化区域，按现有叠放顺序同步绘制受影响区域。最终完整帧仍由后台生成；局部橡皮、整笔删除、荧光笔与铅笔重叠均有像素回归。

公式作为 `PageObjectKind.FORMULA` 保存，`text` 保留可编辑 LaTeX，来源笔迹、布局和局部擦除随页、整本与备份保留。来源笔迹不被识别器改写。页内复制／导入沿用原有来源 ID 重映射和事务。

V76 及更早版本无法读取包含公式对象的新资料。新版本可继续读取已有笔记；不要用旧版本打开新公式资料。如需普通图片／PDF，使用新版本导出。没有删除或重建用户原资料的操作。

## 识别与排版来源

随包离线模型为 [Texo / FormulaNet](https://huggingface.co/alephpi/FormulaNet)，固定修订 `b2668efe5112082846fde4d446b9bfaab3989533`；编码器、解码器与配套文件共约 80 MB。输入只在本机处理。词表、模型哈希见 `app/src/main/assets/asset-manifest.json`，来源元数据见 `formula/MODEL-SOURCE.json`。

排版使用 [JLaTeXMath Android 0.2.0](https://github.com/noties/jlatexmath-android/tree/v0.2.0)。许可及链接例外随包保存于 `assets/licenses/`。公式输入限制长度、嵌套深度及文件／宏命令；不能用数学编辑器执行 TeX 文件操作。

模型输出仍可能混淆函数名、希腊字母与形近符号。模型分数未经准确率校准，因此公式候选必须校对后才保存。合成或注入候选测试只证明编辑、事务与渲染流程，真人样本的识别结果单独记录，不混计为准确率。
