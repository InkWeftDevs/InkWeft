# 墨织 v35：笔记内导图与恢复流程

版本 `0.0.35-integrated-mindmap`（35），安装名称“墨织工作台预览”。

## 如何使用

1. 打开笔记，点击顶部导图图标。宽屏与笔记并排，窄屏显示导图面板；右上角关闭可回到书写。
2. 图名下拉框选择主图／独立图，“新建图”创建当前笔记里的图。摘要卡、大纲和思维导图使用同一内容。
3. 用摘录笔或套索选中手写，进入摘录后选择目标图及分支，点击“添加到这里”；未选分支时放到根主题。随后再填写自己的理解。
4. 摘要详情的“复用到脑图新位置”只增加引用，同卡跨图编辑同步。选择节点后可“移除此节点（保留摘要卡）”。
5. 点击“返回来源区域”才跳转原文。关闭重开、普通编辑、折叠保留本次图视野；“适配当前”和“排布全部主题”由你主动触发。
6. 概览版本冲突保留草稿，重新加载后可编辑再提交；结果待核对则重试原操作，不另建一份。

旋转与窗口变化保留图面板和未提交摘要草稿。落笔／保存期间，改变文档布局的关闭、回源和摘要弹窗入口暂不可用，抬笔提交后恢复。
