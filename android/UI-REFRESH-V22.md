# v22 纯白工作台

界面以用户提供的笔记软件图片为参考；当前视觉方向为全局纯白背景、独立封面书库、细边分区及蓝色操作选态。

## 视觉规则

| 部位 | 处理 |
| --- | --- |
| 全局界面背景 | 纯白 `#ffffff`；含侧栏、设置、导图、诊断和编辑器外围 |
| 资料库 | 封面独立排列，标题最多两行，日期居中；新建为虚线封面 |
| 文字 | 深灰 `#20242d`，次要文字 `#626b79` |
| 操作 | 蓝色 `#176bb5`，选态底 `#e9f2fb` |
| 浮层 | 笔盒 20dp 圆角／4dp 阴影，参数卡 6dp 阴影 |
| 思维导图 | 白色画布、蓝色根主题、白色普通主题、细连接线 |

纸张、自定义封面、既有笔迹与导入文档按内容显示。应用仍为浅色，系统栏使用深色图标；系统深色设置不会将当前界面背景改暗。

## 交互

导图缩放、适配独立置底。关闭按钮固定在右上，窄屏／大字号时次要操作换行并可滚动。节点只保留有意义的折叠数量，操作可访问说明与大纲替代路径保留。主笔盒、收藏笔盒及自动美化沿用既有行为。

## 技能使用与范围

使用 ui-ux-pro-max：系统方向搜索的混合网页建议未直接采用；窄化 style 查询 `minimal neutral workspace` 匹配 Minimalism & Swiss Style，采用清晰层次、网格和克制装饰。Compose 查询 `theme surface colors` 匹配集中语义主题建议。具体背景、书库结构和圆角以用户图片及明确要求为准。

验证沿用现有书库、笔盒和学习共享卡测试，增加大字号关闭按钮可见性断言。实机步骤见 T55；实际结果见交付回执。
